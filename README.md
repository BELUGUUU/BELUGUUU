## 📦 仓库解析

### 🧮 [cpp · 数据结构课设题解](https://github.com/BELUGUUU/cpp)

《数据结构》课程设计 OJ 题解合集，**29 道题完整实现**，全部以 `g++ -O2 -std=c++11 -Wall` 编译，**零告警**。

- **数据结构全覆盖**：顺序表、二叉排序树（迭代插入防退化爆栈）、手写哈希（多项式 / ELF · 线性探测 / 链地址双策略）、双向链表 ADT、二叉树与表达式树
- **经典算法题**：中缀转后缀、后缀表达式求值、Josephus 问题、带权路径长度 (WPL)、24 点搜索回溯（子集按下标划分）
- **图论题**：推箱子 BFS / DFS 双版本、自来水管道铺设、最小时间、修路 (Repairing a Road)
- **同一道题多实现对比**：单词检查用顺序表 / BST / 哈希三种结构各写一遍，配合 benchmark 做复杂度实测
- **性能实验结论**（仓库内含 `benchmark_result.txt`）：
  - ELF hash 低位随机性弱，`(h & mask)` 取模时平均探测 336.84 次，补一次终混后降到 **1.42** —— 哈希函数必须与取模方式配套
  - 线性表 R/D 操作用 `rev` 逆转标志把 O(n) 逆置降到 **O(1)**，规模 ×3 时实测增长 2.8 倍（线性）vs 物理逆置 11 倍（平方）

> 每份 `main.cpp` 可直接提交 OJ，样例输出逐字符一致，各实现间做过随机对拍。
